# Android device tree for Tecno Camon 40 Pro 4G (CM6)

## Device specifications

| Feature          | Specification                                                   |
|------------------|-----------------------------------------------------------------|
| SoC              | MediaTek Helio G100 Ultimate (6 nm)                             |
| CPU              | Octa-core (2×2.2 GHz Cortex-A76 & 6×2.0 GHz Cortex-A55)        |
| GPU              | Mali-G57 MC2                                                    |
| RAM              | 8GB                                                             |
| Storage          | 256GB                                                           |
| Display          | 6.78" 1080×2436 AMOLED, 120Hz, HDR, Corning Gorilla Glass 7i   |
| Rear camera      | 50 MP (wide), f/1.9, OIS + 8 MP (ultrawide)                    |
| Front camera     | 50 MP, f/2.5 (wide), PDAF                                       |
| Battery          | 5200mAh, 45W wired                                              |
| Dimensions       | 164.4 × 74.3 × 7.3 mm (6.47 × 2.93 × 0.29 in)                 |
| Weight           | 178 g (6.28 oz)                                                 |
| OS               | Android 15 (upgradable to Android 16), HIOS 15                  |
| Sensors          | Fingerprint (under display, optical), accelerometer, gyro, proximity, compass |
| Connectivity     | Wi-Fi, Bluetooth, NFC, Infrared, FM radio, GPS                  |
| IP rating        | IP68/IP69 dust/water resistant                                  |
| Colors           | Emerald Lake Green, Galaxy Black, Glacier White                 |
| Models           | CM6                                                             |

## Build instructions

```
source build/envsetup.sh
brunch CM6
```
